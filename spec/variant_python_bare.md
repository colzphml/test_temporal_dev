# Вариант реализации: чистый Python

- Python из `./.venv` (установлен `httpx==0.28.1`; стандартная библиотека —
  без ограничений).
- НИКАКИХ workflow-движков и оркестраторов (Temporal, Airflow, Celery и т.п.) —
  только собственный код.
- Temporal-переменные окружения в этом варианте игнорируй.
- Решение — в `solution/`; точка входа `solution/run.sh` (контракт в SPEC,
  раздел 9).
- Отладка: `make state`, `make ledger ORDER=ORD-1001`; stdout/stderr твоего
  процесса виден в выводе `make verify`.
- Замечание об окружении: системный HTTP-прокси macOS может перехватывать
  запросы python-клиентов к localhost. `make verify` выставляет NO_PROXY для
  твоего процесса сам; при ручном запуске своих скриптов учитывай это
  самостоятельно (NO_PROXY / настройки http-клиента).
